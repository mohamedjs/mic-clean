التسطيب

محتاج Node.js 18+ بس، من غير npm install. نزّل الكود الأول:

git clone https://github.com/mohamedjs/mic-clean.git
cd mic-clean

أو نزّله ZIP. وبعدين اختار نظامك:

  1. شغّل السكريبت. هيعمل خدمة بتقوم مع الجهاز:
    bash install-linux.sh
  2. للضاغط والليميتر (اختياري):
    sudo apt install swh-plugins        # Ubuntu / Debian
sudo dnf install ladspa-swh-plugins # Fedora
sudo pacman -S swh-plugins          # Arch
  3. في البرامج اختار المايك Mic (Mohamed). التنضيف بيحصل في PipeWire، فمش لازم الداشبورد تفضل مفتوحة.
  1. شغّل السكريبت. هيسطّب BlackHole وswitchaudio-osx بـ Homebrew:
    bash install-mac.sh
  2. اعمل Restart مرة واحدة لو BlackHole لسه متسطب.
  3. في الداشبورد: الدخل = المايك بتاعك، الخرج = BlackHole 2ch، ودوس «▶ شغّل».
  4. في زوم/OBS اختار المايك BlackHole 2ch. سيب الأبلكيشن مفتوح (ممكن تصغّره). يشتغل على Chrome أو Edge.
  1. نزّل VB-CABLE (مجاني)، وشغّل VBCABLE_Setup_x64.exe كـ Administrator، واعمل Restart.
  2. شغّل السكريبت في PowerShell. هيتأكد من Node ويخلّي السيرفر يقوم مع الجهاز:
    powershell -ExecutionPolicy Bypass -File install-windows.ps1
  3. في الداشبورد: الدخل = المايك بتاعك، الخرج = CABLE Input، ودوس «▶ شغّل».
  4. في زوم/تيمز/ديسكورد/OBS اختار المايك CABLE Output (VB-Audio Virtual Cable). سيب الأبلكيشن مفتوح. يشتغل على Chrome أو Edge.
